# PDF Dark Reader

Windows PDF reader focused on customizable page color inversion.

## Goals
- Open and browse PDF files.
- GPU-based reading inversion.
- Custom dark background color and inversion strength.
- Scan/image PDF and vector PDF support.
- Export an inverted PDF.
- Future: pressure-sensitive pen annotation with Windows Ink.

## Direction
Windows x64 first. Keep the application local/offline and lightweight.
